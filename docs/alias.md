# kato alias

`kato alias` is an interactive alias manager that lets you browse, add, edit,
delete, and search your shell aliases without editing config files by hand.

## Setup

On first run, kato writes a shell init script to `~/.kato/` and prints a hint
with the line to add to your shell profile. You only need to do this once.

| Shell | Init script | Add to profile |
|-------|------------|----------------|
| bash | `~/.kato/init.sh` | `source "$HOME/.kato/init.sh"` |
| zsh | `~/.kato/init.sh` | `source "$HOME/.kato/init.sh"` |
| fish | `~/.kato/init.fish` | `source "$HOME/.kato/init.fish"` |
| PowerShell | `~/.kato/init.ps1` | `. "$HOME/.kato/init.ps1"` |

After sourcing the init script, restart your shell (or re-source the profile)
and your aliases will be available.

## Usage

```sh
kato alias
```

Opens the interactive TUI.

## Controls

| Key | Action |
|-----|--------|
| `↑` / `↓` | Move selection |
| `j` / `k` | Move selection (vim-style) |
| type | Filter aliases by name or command |
| `a` | Add a new alias |
| `enter` / `e` | Edit the selected alias |
| `d` | Delete the selected alias (with confirmation) |
| `c` | Copy the alias command to clipboard |
| `q` / `esc` | Quit |

**In the add / edit form:**

| Key | Action |
|-----|--------|
| `Tab` / `Shift+Tab` | Switch between name and command fields |
| `Enter` | Save |
| `Esc` | Cancel |

## Storage

Aliases are stored in `~/.kato/aliases` as plain text — one alias per line:

```
gs=git status
ll=ls -la
# this is a comment
```

- Only the first `=` is the delimiter, so commands may contain `=`.
- Blank lines and lines starting with `#` are ignored.
- The file can be hand-edited at any time.

## Shell init script

The init script (`~/.kato/init.sh` etc.) is regenerated by kato on every
install or upgrade. It contains two things:

1. The `kato` wrapper function that enables `kato nav` to change your working
   directory (required for the `cd` effect).
2. An alias loader that reads `~/.kato/aliases` at shell startup.

The file is owned by kato — do not edit it manually, as changes will be
overwritten on the next install.
